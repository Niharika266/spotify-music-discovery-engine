# Spotify Music Discovery Engine

## Overview

A data-driven Spotify music analysis and recommendation project built using Python, SQL, Machine Learning and a web API.

## Objective

The goal of this project is to analyze Spotify music data, understand song and audio-feature patterns, and eventually build a system that can recommend similar songs.

## Dataset

Spotify Tracks Dataset containing information about:

- Songs
- Artists
- Genres
- Popularity
- Audio features

Important audio features include:

- Danceability
- Energy
- Loudness
- Speechiness
- Acousticness
- Instrumentalness
- Liveness
- Valence
- Tempo
